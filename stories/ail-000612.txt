I write and run a home brew pathfinder 2e campaign. I used to use chatgpt to brainstorm and write journal entries (primarily using it to come up with random encounter ideas or rewrite things in various tones and styles for consistency). It kinda worked. 

With gemini tho...

Custom gem to take any image and output a image generation prompt to replicate it in a consistent dark fantasy, digital oil painting style. It automatically detects if it should make an item icon, a character portrait, or a scene/environment with specific aspect ratios for each. 

Then I have another gem that takes the output from the previous gem and makes an image for my campaign. It has custom instructions that expect the output from my other gem specifically. 

I have another gem that takes any picture and outputs a bust portrait with the same style as my other gems. Designed to work with images generated by the previous gem but works well with any picture of a person or character. 

Then I use notebookLM and Obsidian.md to actually organize my notes and write the campaign. It is amazing at scanning all of my notes and giving me a short bullet list of reminders that I can refer back to mid session. It has been a game changer. I can easily keep track of multiple factions, economies, goals, npcs, etc. After each session i can dump my quick mid session notes into my set up and have it analyze the new notes and point out places I need to update existing notes. Or point out repercussions that I hadn't considered. It's been incredible so far.
